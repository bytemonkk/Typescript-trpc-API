# TypeScript tRPC API

A production-ready backend API built with TypeScript, Node.js, Express, tRPC, and Zod.

## Tech Stack

- TypeScript
- Node.js
- Express.js
- tRPC
- Zod
- pnpm

## Features

- Type-safe API with tRPC
- Request validation with Zod
- Modular backend structure
- Express integration

## Getting Started

```bash
pnpm install
pnpm dev
